# PortedSplashScreen

向 ClassIsland 添加更丰富多彩的启动画面！
`MoreSplashScreen的第三方移植版本`

## 特性

添加了以下样式的启动屏幕：

- Android Studio
- Microsoft 365 [^1]
- Microsoft Office（旧） [^1]
- IslandOnTop
- Adobe Photoshop [^2]

[^1]: Microsoft、Microsoft 365 和 Microsoft Office 是 Microsoft Corporation 的商标。
[^2]: © 1990-2024 Adobe. All rights reserved. Adobe, the Adobe logo, Adobe Photoshop are either registered trademarks or trademarks of Adobe in the United States and/or other countries.

PortedSplashScreen增加了有关圆角，网络图片与轮播的拓展功能

## 需求

本插件需要 2.0.0.0 及以上版本的 ClassIsland。

## 使用方法

1. 在插件市场安装本插件
2. 在【应用设置】->【更多启动屏幕】[打开 PortedSplashScreen 设置](classisland://app/settings/com.ported.classisland.portedSplashScreen.settings)设置你喜欢的启动屏幕样式
3. 点击设置页下端的预览按钮预览启动效果
4. 重启应用使设置生效

## 背景素材

内置启动背景（Android Studio、Adobe Photoshop 两种启动屏幕使用的插画）为第三方作品，由于某些原因，图片**不随本插件分发**。插件会在需要时自动从原版仓库下载
